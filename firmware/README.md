# M0601 / M0601C Firmware Repository

本目录收录了 M0601 / M0601C 系列电机的原厂及定制无温控固件，以及完整的固件升级（IAP）与恢复说明。

## 固件文件清单

1. **`01a_no_temperature.bin` (18,616 字节)**:
   - **适用场景**：特殊定制版 M0601 / M0601A / 无 NTC 电机。
   - **修改特性**：原厂固件若直接刷入定制硬件，因 NTC 热敏电阻阻值或电路不一致，会误报超高温度（>80°C）并触发过热保护（Fault Bit 4 / `0x10`），导致电机无法启动。本固件切断了伪过热故障置位，使电机可在定制硬件上正常运行全部速度环、位置环与电流环功能。
2. **`M0601C_stock_backup.bin` (16,972 字节)**:
   - **适用场景**：标准原厂 M0601C-111 / FIT1042 / FIT1038。
   - **修改特性**：原厂出厂标准固件备份（含完整的 80°C 过热保护与板载 NTC 校验）。

## 固件安全与防变砖机制

无论刷入哪个固件，**电机绝对不会变砖**，原因如下：

1. **硬件独立 Bootloader 保护**：
   - 电机主控（Linko LKS32MC08x / Cortex-M0）前 8KB（`0x00000000 ~ 0x00001FFF`）固化了独立 Bootloader。
   - 用户 Application 位于 `0x00002000` 开始的高地址扇区。
   - RS485 IAP 升级协议只向 `0x00002000` 后的 App 扇区写入数据，**Bootloader 本身绝不可能被覆盖损坏**。
2. **冷启动上电守护窗口**：
   - 只要给电机断开 18V 电源并重新通电，MCU **无论内部 App 固件是否损坏**，都会在最初 1~2 秒内广播 `AA 55 FF` 信标并开放刷机握手窗口。
   - 只要重新上电，随时可使用 `m0601 update` 或原厂 `untitled.exe` 重新刷机或刷回原厂固件。

## 固件烧录方式

### 方式 1：使用 `m0601-cli`（推荐）
```bash
# 自动软件重启并更新固件（单只电机连接 RS485 总线）
m0601 update --port COM3 --bin firmware/01a_no_temperature.bin

# 或冷启动烧录（先断电，运行命令后上电）
m0601 update --port COM3 --bin firmware/01a_no_temperature.bin --no-reboot
```

### 方式 2：使用原厂图形化工具（`untitled.exe`）
1. 运行 `untitled.exe`；
2. 选择串口号并点击“打开串口”（115200 波特率）；
3. 选中 `01a_no_temperature.bin`；
4. 电机通电，收到 `AA 55 FF` 提示后立即点击“固件更新”；
5. 显示“固件更新完成”后重新上电即可。
